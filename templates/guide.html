Methodology, and what this page will not tell you

What is compared

  • Scope is a query over the catalog's own category field: {% for c in guide.categories %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}. {{ stats.products_in_scope }} tracked product{{ "s" if stats.products_in_scope != 1 }} fall into it today.
  • Ranking is by {{ metric.label }} — the retailer's price for a single standalone unit divided by that product's {{ metric.spec_label }} in {{ metric.spec_unit }}. A product's rank is set by the cheapest {{ metric.label }} available at any tracked retailer; the price and the rating in every row always describe the same variant.
  • Only in-stock offers set a rank. A ranking is a buying recommendation, so an offer whose variant was sold out at the last check cannot claim a position, however cheap it is. {{ stats.offers_sold_out }} of the {{ stats.offers_shown }} prices on this page are sold out; they stay in the tables, marked, because the price is still real information. {% if stats.products_sold_out_only %}{{ stats.products_sold_out_only }} product{{ "s" if stats.products_sold_out_only != 1 }} on this page {{ "are" if stats.products_sold_out_only != 1 else "is" }} unranked purely because every offer we can rate is sold out.{% endif %}
  • Prices come from {% if stats.retailers %}{% for r in stats.retailers %}{{ r }}{% if not loop.last %}, {% endif %}{% endfor %}{% else %}no retailer, on this build{% endif %}. Each is that retailer's own published price for its own listed variant, as scraped. Nothing is converted, adjusted, or estimated, and shipping and tax are not included.

What is withheld, and why

  • Bundles and multi-unit packs get no {{ metric.label }}. {{ stats.offers_bundle }} of the {{ stats.offers_shown }} prices on this page are kits or packs. Dividing a kit's price by one component's {{ metric.spec_label }} produces a number that looks precise and is wrong, so it is not printed. The prices themselves are still shown.
  • Unknown {{ metric.spec_label }} withholds the rating. {{ stats.products_unranked }} product{{ "s" if stats.products_unranked != 1 }} in scope publish{{ "" if stats.products_unranked != 1 else "es" }} no {{ metric.label }} at all; each is listed above with its reason. A missing number here is a gap Helios is admitting to, not a product being hidden.
  • Old data comes off the page. Any price older than {{ stats.stale_max_hours }} hours is withheld and marked data-withheld="stale" rather than shown with a caveat. {{ stats.withheld_stale }} price{{ "s" if stats.withheld_stale != 1 }} on this page {{ "are" if stats.withheld_stale != 1 else "is" }} currently withheld for age.
  • Anything under verification comes off the page. When an automated audit finds a displayed number disagreeing with its own stored source, that variant is quarantined and withheld until it is re-verified. {{ stats.withheld_quarantine }} price{{ "s" if stats.withheld_quarantine != 1 }} on this page {{ "are" if stats.withheld_quarantine != 1 else "is" }} currently quarantined.

  • Corrupt prices come off the page. {{ stats.withheld_unreadable }} stored price{{ "s" if stats.withheld_unreadable != 1 }} on this page {{ "are" if stats.withheld_unreadable != 1 else "is" }} not a usable number and {{ "are" if stats.withheld_unreadable != 1 else "is" }} withheld rather than printed.
    • {% endif %} {% if stats.products_with_conflicts %}
  • Same SKU, different item. {{ stats.products_with_conflicts }} product{{ "s" if stats.products_with_conflicts != 1 }} on this page {{ "have" if stats.products_with_conflicts != 1 else "has" }} a SKU that two retailers describe differently — a different pack quantity, or a unit at one and a bundle at the other. Those rows carry a warning, because two rows with the same label are not necessarily the same purchase.
    • {% endif %} {% if stats.provenance_cross_retailer or stats.provenance_unquoted %}
  • Provenance of the divisor. {% if stats.provenance_cross_retailer %}{{ stats.provenance_cross_retailer }} rating{{ "s" if stats.provenance_cross_retailer != 1 }} on this page divide{{ "" if stats.provenance_cross_retailer != 1 else "s" }} by a figure quoted verbatim from a different tracked retailer's listing than the one being priced.{% endif %} {% if stats.provenance_unquoted %}{{ stats.provenance_unquoted }} rating{{ "s" if stats.provenance_unquoted != 1 }} divide by a {{ metric.spec_label }} figure that carries no verbatim quote from any retailer listing — it is the manufacturer's nameplate rating as recorded in the catalog. Capacity figures elsewhere on this site are quote-backed; {{ metric.spec_label }} is not, yet.{% endif %} Every rating carries a data-spec-provenance attribute saying which case applies.
    • {% endif %}

Data freshness

  • {% if stats.newest %}The freshest price on this page was read {{ stats.newest.replace("as of ", "") }}; the oldest {{ stats.oldest.replace("as of ", "") }}. Every price shows its own age. {% else %}No priced data is currently displayed on this page.{% endif %}
  • Scrapes are run on demand rather than on a fixed schedule, so an age of a few days is normal. A retailer can change a price at any moment after a scrape; the age beside each price is how far behind the number could be. Stock can change faster than price, so confirm availability on the retailer's own page before buying.
  • Rankings recompute from scratch on every build. Nothing on this page is hand-written or carried over from a previous version.

Commercial disclosure

  • Every outbound retailer link on this page carries rel="nofollow sponsored". Ranking is computed from price data alone; no retailer can pay for a position, and retailers with no commercial relationship to Helios are ranked alongside the rest. Full terms are in the affiliate disclosure.
